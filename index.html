Arquitectura Interna de Linux

Kernel Space

Acceso directo e ilimitado al hardware, memoria y CPU.

User Space

Espacio restringido donde corren programas de usuario de forma aislada.

/ - Directorio Raíz del sistema
/home - Carpetas personales de usuarios
/etc - Configuraciones del sistema

Ecosistema de Distribuciones

Ubuntu

Basada en Debian; popular en equipos personales, nube y servidores. Cuenta con versiones LTS de soporte extendido.

Paquetes: APT / DEB · Entornos: GNOME, Kubuntu (KDE)

Debian

Distribución comunitaria reconocida por su estabilidad. Se usa en servidores y también como base de muchas otras distribuciones.

Paquetes: APT / DEB · Versiones: Stable, Testing y Unstable

Fedora

Proyecto comunitario patrocinado por Red Hat; incorpora tecnologías recientes y sirve como plataforma para probar innovaciones.

Paquetes: DNF / RPM · Ediciones: Workstation, Server e IoT

Arch Linux

Modelo rolling release y enfoque minimalista. El usuario configura el sistema y selecciona sus propios componentes.

Paquetes: Pacman · Documentación: Arch Wiki

Linux Mint

Orientada a escritorio, con una experiencia familiar y herramientas gráficas sencillas. Sus ediciones principales se basan en Ubuntu.

Paquetes: APT / DEB · Escritorio: Cinnamon, MATE o Xfce

Red Hat Enterprise Linux

Plataforma empresarial con ciclo de vida, certificaciones y soporte comercial para centros de datos y nube.

Paquetes: DNF / RPM · Gestión empresarial: suscripciones y soporte Red Hat

Rocky Linux

Distribución empresarial comunitaria compatible con RHEL, pensada para servidores y cargas de trabajo de larga duración.

Paquetes: DNF / RPM · Enfoque: estabilidad y compatibilidad empresarial

openSUSE

Ofrece Leap, de versiones estables, y Tumbleweed, rolling release. YaST facilita la administración gráfica del sistema.

Paquetes: Zypper / RPM · Variantes: Leap y Tumbleweed
